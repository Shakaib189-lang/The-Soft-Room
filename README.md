# The Soft Room
The Soft Room is a modern e-commerce website for mattresses, pillows, bedding, and home décor products.
It provides a simple and user-friendly shopping experience with different product categories.
Users can browse products, search and filter items, add products to the cart, and place orders.
The website also includes product details, checkout, shipping, returns, FAQ, and contact pages.
It is built using HTML, CSS, and JavaScript with a responsive and clean design.
This project helped me improve my web development and e-commerce website skills.
